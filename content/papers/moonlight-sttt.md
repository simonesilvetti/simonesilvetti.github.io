## The tool

**MoonLight** monitors temporal and spatio-temporal properties of mobile, spatially distributed and interacting entities, such as biological and cyber-physical systems.

- Space is a **weighted graph** describing how the entities are arranged.
- Nodes and edges carry attributes for physical quantities and logical states that **evolve over time**.
- It supports the Spatio-Temporal Reach and Escape Logic (**STREL**).

MoonLight is written in Java and can be used as a standalone command line tool, as a Java API, or through **Matlab™** and **Python** interfaces.

## This paper

The journal version describes the tool, its interfaces and its scripting language, using a sensor network and a bike sharing system as examples. Performance is evaluated against tools specialised in monitoring temporal properties only.

It extends the [RV 2020 tool paper](/papers/moonlight).
