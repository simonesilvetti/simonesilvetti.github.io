# Learning Ruby

Today I started studying Ruby.

## First impressions

I really like how simple the language is.

```ruby
puts "Hello, world!"

[1, 2, 3].each do |number|
  puts number * 2
end
```

## Some basic concepts

| Concept | Example                |
|---------|------------------------|
| String  | `"hello"`              |
| Symbol  | `:name`                |
| Array   | `[1, 2, 3]`            |
| Hash    | `{ key: "value" }`     |

To learn more: the [official documentation](https://www.ruby-lang.org/en/documentation/).
